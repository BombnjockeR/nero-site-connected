Equipment Options

Custom gear can roll random bonus options (a gacha-style system). Each piece has an Option 1 and Option 2 slot.

Rules

  • Option 1: Pay 1,000,000 zeny + 2 Nero Token for a random Option 1. Works on gear from +0 to +10.
  • Option 2: Pay 2,000,000 zeny + 4 Nero Token for a random Option 2. Works only on gear from +7 to +10.
  • You can roll an option a maximum of 10 times per equipment. To keep rolling on the same gear, pay 2,000,000 zeny to reset.
  • To keep the option but change only its value, use a Nero Magnifier.
  • Options stack across pieces, so the same stat can appear on multiple slots.

Nero Magnifier — Re-roll Option Values

Re-rolls only the value of an equipment option or costume garment enchant. Re-rolling basic gear gives a random value.

The table below applies only to Costume Garment Enchant re-rolls:

Tier Upgrade Chance Ascension Stone needed Nero Magnifier needed
I → II 55% 1 1
II → III 30% 1 1
III → IV 15% 2 1
IV → V 7% 2 1
