Ascension

Era Crystal: Ascension — Garment only. Each enchant grants only one of the six lines below — not all of them. The rarity you roll decides which tier (I–V) that single line comes at. See Era Options for how to use crystals and rarity odds.

To upgrade the tier later without changing which line you already have, use a Nero Magnifier with an Ascension Stone: Garment — see the Equipment Options page for magnifier odds.
